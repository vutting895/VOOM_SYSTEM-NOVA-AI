# Knowledge Center Workstream

**Governance owner:** VOOM System + NOVA Command Center  
**Execution scope:** Ecosystem governance knowledge, operational documentation and runbooks.

## Responsibilities
- Maintain architecture decisions, system maps, ownership records and operational runbooks.
- Index approved documentation and link source evidence.
- Track document owner, version, freshness and supersession.
- Provide discoverable knowledge to Command Center and authorized internal services.

## Boundaries
- Does not become a duplicate research/data/model repository.
- Datacenter remains the sole owner of research lineage, datasets, features/labels, training artifacts and model registry.
- Do not ingest secrets, credentials, private customer records or unapproved sensitive data.

## Required evidence
Document owner, source repository/path, version or SHA, review date, links, access classification and superseded-document references.
