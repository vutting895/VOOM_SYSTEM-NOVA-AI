# Command Center Internal Workstreams

These are four managed workstreams, not separate ChatGPT Projects and not automatically separate services. They are governed from the VOOM System + NOVA Command Center. Work execution may occur in the owning repository.

| Workstream | Specification | Governance owner | Reporting |
|---|---|---|---|
| Security & Identity | [Security & Identity](security-identity/README.md) | Command Center | Report security work and evidence per affected repository |
| Infrastructure & DevOps | [Infrastructure & DevOps](infrastructure-devops/README.md) | Command Center | Report infrastructure changes per owning repository |
| Knowledge Center | [Knowledge Center](knowledge-center/README.md) | Command Center | Report docs/runbooks; Datacenter retains research lineage |
| QA & Testing | [QA & Testing](qa-testing/README.md) | Command Center | Report test evidence per repository and exact commit |

No workstream authorizes deployment, paid infrastructure, secret/permission changes, production data changes or trading execution. Those require their own approval gates.
