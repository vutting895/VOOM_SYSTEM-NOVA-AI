# NOVA v1.0 External Data Ingestion Policy

## Canonical target
- Market: XAUUSD only.
- Base interval: M1.
- Context intervals: M5, M15, M30, H1.
- Canonical timestamps: UTC, timezone-aware.
- Signal generation: closed bars only.
- Broker aliases such as XAUUSDm map to canonical XAUUSD while retaining original broker symbol in provenance.

## Accepted source classes
1. Broker-exported MT5 history authorized by the user; scrub account identifiers.
2. Licensed/public historical market data where redistribution and usage terms permit.
3. Macro series with explicit publication/availability timestamps and attribution.
4. Economic-event calendars with source, timezone and revision metadata.
5. Synthetic fixtures generated by NOVA for tests only.

## Rejected by default
- Unlicensed or unclear bundled CSV/ZIP/Parquet files.
- Compiled EA binaries, DLLs or opaque model checkpoints.
- Credentials, account statements, personal data or broker data without authorization.
- Data without timezone, symbol, interval, source or coverage metadata.
- Future/incomplete candles in historical signal evaluation.

## Required manifest
dataset_id, source_repository, source_url, source_file, upstream_commit, provider, instrument, broker_symbol, timeframe, start_utc, end_utc, timezone, price_basis, retrieved_at_utc, license, provider_terms_url, file_format, row_count, sha256, missing_intervals, duplicate_count, validation_status, transformations, code_version.

## Validation gates
- OHLC integrity and positive prices.
- UTC monotonicity and duplicate checks.
- Gap report against expected trading sessions; weekends/holidays are not missing bars.
- Spread and bid/ask consistency where available.
- MTF aggregation only from complete base-bar buckets.
- Point-in-time available_at for macro/events and derived higher-timeframe features.
- Chronological train/validation/OOS separation.
- Raw source immutable; normalized and approved data are separate outputs.

## Storage
data/external/manifests/
data/external/source_metadata/
data/raw/xauusd/
data/normalized/xauusd/
data/approved/xauusd/
data/synthetic/tests/

Large raw datasets stay outside Git (local volume or approved object storage). Git contains manifests, schemas, validation reports and small licensed fixtures only.
