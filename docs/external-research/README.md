# External Research Data Integration

This directory records external data and engineering references reviewed for NOVA v1.0. It is not a collection of copied trading systems.

## Import policy
- Prefer original, reproducible source data with documented provider terms and hashes.
- Never commit credentials, account data, private datasets, or binaries with unclear redistribution rights.
- Do not treat sample/demo data as market truth.
- Keep raw data immutable and separate from normalized/approved datasets.
- Every dataset needs source, instrument, timeframe, timezone, retrieval time, coverage, license/terms, SHA-256 and validation report.
- All imported market data is research-only until validated.
- Public repository status does not automatically grant rights to bundled datasets or model weights.

See SOURCE_REGISTER.md and DATA_INGESTION_POLICY.md.
