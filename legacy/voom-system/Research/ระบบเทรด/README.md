# ระบบเทรด — VOOM AI SNIPER

โฟลเดอร์นี้คือคลังระบบเทรดที่ผ่านการวิจัย ตรวจสอบ และอนุมัติให้ AI เรียกใช้งานได้ ไม่ใช่พื้นที่เก็บไอเดียดิบ

## กติกาการนำเข้า
1. เก็บเฉพาะกลยุทธ์/ระบบที่มีแหล่งอ้างอิง วิธีการชัดเจน และบันทึกผลการตรวจสอบ
2. ทุกระบบต้องมีเอกสาร SYSTEM.md และ manifest.json ระบุเวอร์ชัน แหล่งข้อมูล ข้อจำกัด สถานะการทดสอบ และ checksum
3. แยกสถานะ research, backtest_passed, demo_validated, approved_for_ai และ retired ให้ชัดเจน
4. AI ใช้ข้อมูลที่ approved_for_ai เป็นบริบทเพื่อวิเคราะห์/พัฒนาระบบเท่านั้น ไม่ถือเป็นคำสั่งให้เปิดออเดอร์
5. ห้ามเลื่อนสถานะจากการอ่านบทความหรือจากคำตอบ AI เพียงอย่างเดียว ต้องมีหลักฐานและการทดสอบที่ทำซ้ำได้
6. ห้ามบันทึก API keys, broker credentials, account identifiers หรือข้อมูลลับลงในคลังนี้
7. ระบบที่ยังไม่มีผลทดสอบครบต้นทุนซื้อขายจริงต้องติดป้ายข้อจำกัดอย่างเด่นชัด และห้ามเปิด live trading อัตโนมัติ

## โครงสร้าง
- catalog.json — รายการระบบและสถานะสำหรับ MCP/AI
- VOOM_CORE/ — กลยุทธ์หลักของโครงการ
- _templates/SYSTEM.template.md — แม่แบบสำหรับระบบใหม่
- _incoming/ — รายการที่รอตรวจสอบ ห้ามใช้เป็นกลยุทธ์ที่อนุมัติแล้ว

## การเรียกใช้
MCP server มีเครื่องมือ list_trading_systems และ get_trading_system สำหรับให้ AI อ่าน catalog และเอกสารตามสถานะ โดยค่าเริ่มต้นจะแสดงเนื้อหาของระบบที่ approved_for_ai เท่านั้น

## หมายเหตุสำคัญ
คำว่า “พร้อมให้ AI ใช้” หมายถึงพร้อมเรียกอ่านความรู้และใช้ช่วยพัฒนา/ประเมินระบบ ไม่ได้หมายถึงพิสูจน์แล้วว่าทำกำไร หรือได้รับอนุญาตให้ส่งคำสั่งซื้อขายจริง
